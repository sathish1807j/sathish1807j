## Featured Projects

### Chef Claude – AI Recipe Recommendation Web App

**Tech Stack:** React.js, JavaScript, Hugging Face Inference API, Mistral LLM, HTML, CSS

- Developed an AI-powered recipe recommendation application.
- Integrated a Mistral Large Language Model through the Hugging Face Inference API to generate contextual recipes.
- Built a responsive React interface with dynamic rendering of generated results using Markdown.

### AI-Powered Movie Recommendation Engine

**Tech Stack:** Python, PyTorch, Streamlit, Pandas, NumPy, MovieLens Dataset

- Built a personalized movie recommendation system using collaborative filtering and matrix factorization.
- Trained a recommendation model using PyTorch.
- Developed a Streamlit interface for interactive recommendations.
- Implemented cold-start handling for new users.

### HireMind – Multi-Agent AI Interview Simulator

**Tech Stack:** Python, Streamlit, Groq API, LLaMA 3.1, CrewAI

- Developed a multi-agent AI interview simulator with Interviewer, Evaluator, and Feedback Coach agents.
- Automated question generation and evaluation across Technical, HR, and System Design interviews.
- Implemented performance scoring, personalized feedback, and a dashboard for interview analytics.
